## What this is

LFM3 in the Browser is a **reference implementation** of Liquid AI's LFM3-Omni-2B for websites and web apps. The
whole model runs on the visitor's GPU through WebGPU, with no server-side inference, no build step and no runtime
dependencies. It is an implementation by Mage / Toaster Club LLC. The model is Liquid AI's, used under the LFM Open
License v1.0 (see [Terms of use](#terms-of-use-you-must-keep)).

- Live: <https://lfm.toasterclub.com>
- The site is the static folder `public/`. Cloudflare Workers serves it as static assets; `wrangler.jsonc` holds
  the config, and there is no Worker script.
- Pushing to `main` redeploys the live site through Cloudflare Workers Builds.

## Set it up

Run these from the repository root. They need Node 18+ and Python 3.10+.

1. Install Wrangler, pinned by `package-lock.json`:

   ```bash
   npm ci
   ```

2. Check every weight part against its recorded sha256 (77 parts, about 1.3 GB):

   ```bash
   python3 tools/pack_weights.py --verify
   ```

3. Serve the site locally, then open <http://localhost:8787> in Chrome, Edge or Safari:

   ```bash
   npx wrangler dev
   ```

   Without Node, `python3 tools/serve.py --root public --port 8080` serves the same folder at
   <http://localhost:8080>.

4. To deploy your own copy, sign in once with `npx wrangler login`, or set `CLOUDFLARE_API_TOKEN` in CI:

   ```bash
   npx wrangler deploy
   ```

   Or connect the repository in the Cloudflare dashboard (**Workers & Pages → Create → Import a repository**), and
   every push to `main` deploys. Any static host also works: upload `public/` as it is.

## Map

```

  index.html, app.js       the full app: chat, push to talk, Live, photos, spoken replies, memory, settings
  engine/                  the engine: plain ES modules, WebGPU + WGSL, no dependencies
    index.js                 one import for everything below
    loader.js                the happy path: loadLFM3(), loadVision(), loadAudio(), loadSpeech(); device cache
    lfm3.js, kernels.js      the language model and the shared WGSL kernels
    chat.js, tokenizer.js    chat template, memory (System 3), spoken turns, ASR; the tokenizer
    vision.js                image preprocessing + encoder;   audio.js  log-mel + speech encoder (+ streaming)
    speech.js                spoken replies: depth decoder + voice codec;   listen.js  microphone + resampler
    pngbytes.js, store.js    weight part containers; IndexedDB
  examples/chat.html       the smallest page that uses the engine (one loadLFM3() call)
  weights.js               the weight sets' tensor lists and part URLs (generated by tools/pack_weights.py)
  weights/<set-id>/        weight parts (PNG byte containers) + chunks.json (sha256 per part); NOTICE.txt
  licenses/                the licenses and NOTICE, served to everyone who downloads the weights
tools/                   exporters, packing, icons, PyTorch references, GPU/browser/site tests
docs/                    ARCHITECTURE.md, API.md, WEIGHTS.md, TESTING.md
results/                 measured results quoted in the README
```

## Rules

1. **No build step and no runtime dependencies in `public/`.** The engine is ES modules that import only each
   other. The app must keep working when `public/` is copied to any static host.
2. **Baseline WebGPU only.** No `shader-f16`, no subgroups and no other optional features: f16 is packed into u32
   by hand. Keep every buffer under 1 GiB and at most 10 storage buffers per shader stage (`initDevice()` in
   `lfm3.js`). This is what lets it run on iPhone Safari.
3. **Never edit `public/weights/` by hand.** Regenerate with the exporters and `tools/pack_weights.py` (see
   [docs/WEIGHTS.md](docs/WEIGHTS.md)). Set folders are content hashes, so new weights get new folders and
   `weights.js` follows. Keep each part under 25 MiB, Cloudflare's per-file limit.
4. **Match the model card's prompt format.** That covers:
   - the chat template, with `<think></think>` opening each assistant turn;
   - media wrapped in `<|vision_start|>`…`<|vision_end|>`;
   - the speech instruction "Respond with interleaved text and audio." as the last line of the system prompt;
   - `<|mixed_start|>` for spoken turns;
   - "Perform ASR in <language>." for transcription;
   - greedy text, and audio temperature 0.4 with a 1.2 repetition penalty over 64 frames.

   Any change here needs a GPU check against PyTorch (`tools/node_*_test.mjs`).
5. **Privacy is a feature.** Nothing the user types, says or shows may leave the device. Do not add analytics,
   remote logging or calls that send user content anywhere.
6. **Keep the licenses and credits intact.** That includes:
   - `LICENSE` (Apache-2.0, the code), `LICENSE-LFM.txt` (the model), `NOTICE`, `CITATION.cff`;
   - `public/licenses/`, `public/weights/NOTICE.txt`;
   - the About section in the app's Settings, and the credit line on the setup card;
   - the SPDX header at the top of each source file (add it to new ones).

   If you add a file derived from the model, list it in `NOTICE` as modified. Credit the project as "Mage / Toaster
   Club LLC" (the copyright holder is Toaster Club LLC).
7. **Test before you push to `main`:**
   - static checks on everything you touched: `node --check` for JavaScript, `python3 -m pyflakes` for Python;
   - for engine changes, the GPU tests in [docs/TESTING.md](docs/TESTING.md);
   - after deploying, `python3 tools/site_test.py --base <url>`.

   A push to `main` is a production deploy.

## Common changes

| Change | Where |
| --- | --- |
| The app's look or behavior | `public/index.html` (markup and CSS), `public/app.js` |
| How a page loads the model | `public/engine/loader.js` |
| A shader or the language model | `public/engine/kernels.js`, `public/engine/lfm3.js`; check with `tools/node_bench.mjs` |
| Photos, speech in, speech out | `vision.js`, `audio.js`, `speech.js`; their `tools/node_*_test.mjs` |
| The chat format, memory, spoken turns | `public/engine/chat.js` |
| New or re-quantized weights | `tools/*_export.py`, `tools/png_chunks.py`, `tools/pack_weights.py` |
| Icons and the share card | `tools/make_icons.py` |
