LFM3-Omni-2B: In browser, offline first

LiquidAI's LFM3-Omni-2B runs on this device via WebGPU. It can respond via prompt, speech, and even real-time video + image pipelines. No API is called, and nothing leaves your local device.

Also here: Decide, Liquid's d1-Omni-2B decision model. It answers named questions about a message, JSON, a photo or a recording with calibrated probabilities. And Voice Desk: d1 hears what you say and decides, then this model answers aloud with that decision in mind.

Note: Requires a GPU on the device, Safari 26 or another modern browser.

Instructions

How the assistant should behave in every chat: its system prompt. Leave it empty for the default, “You are a helpful personal assistant.” In voice mode “Respond with interleaved text and audio.” goes last so the model can speak. It stays on this device.

Storage

The model's weights are kept in this browser's storage on this device, so later visits skip the download.

Smoke test

Runs every workflow once on this device with the same inputs everywhere, checks each answer and measures it: text (time to the first token, prefill and decode tokens per second), a photo, a spoken reply, speech recognition, and a push-to-talk turn with a camera picture, as in Live. These are real numbers from your GPU, to compare and share. It plays two short spoken answers and starts a new chat when done. Nothing leaves the device unless you copy, share or save the results.

LFM3 in the Browser is an implementation by Mage / Toaster Club LLC. It runs Liquid AI's LFM3-Omni-2B on this device's GPU with WebGPU, and it is a reference implementation for using the model directly inside websites and web apps: one folder of static files, loaded in one call.
